# Data

Simulated data are generated by the code (`select_then_match/data.py`): nothing to download.

Steps 1, 2 and the CDC part of Step 3 need the public BRFSS 2015 file from Kaggle ("Diabetes Health Indicators
Dataset", Alex Teboul). Put `diabetes_012_health_indicators_BRFSS2015.csv` (or the `diabetes_binary` version) in this
folder. The file is not part of the repository.
